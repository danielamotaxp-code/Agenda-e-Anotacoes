# Agenda Jurídica · Turma de Direito

Site da turma (GitHub Pages) com agenda e caderno de anotações. **O conteúdo é criptografado**: só abre com o acesso da turma (usuário e senha divulgados no grupo).

- `index.html`, `assets/`: o site.
- `data/conteudo.json`: agenda, disciplinas e anotações criptografadas (AES-256-GCM, chave derivada por PBKDF2-SHA256). Gerado no repositório privado `agenda-dados`; não editar aqui.
